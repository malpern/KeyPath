---
title: Window Snapping
---

Open Settings → Rules → Window Snapping to configure shortcuts and preview window positions.

The Activation row shows the current shortcut sequence. Choose Change… to select Leader Key or Quick Launcher. Required supporting rules are checked when you turn on Window Snapping.

Choose Standard or Vim for the action keys. Changing the key layout keeps an off rule off. Hover, focus, or click a position tile to preview it; previews never move your windows. Maximize fills the available screen area; it is not macOS full-screen mode. Center previews a centered window; its actual size is preserved.

Expand More shortcuts for display movement, Spaces, and Undo. Turn the rule on with the switch when ready. If a supporting rule is needed, choose it in the setup sheet and enable both together.
